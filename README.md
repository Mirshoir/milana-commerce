# Milana Commerce

Milana Premium website and customer mobile applications.

## Active mobile app

The approved Android and iOS application is in [`milana_mobile`](milana_mobile).
It is the customer-facing Capacitor app backed by the same SQLite website API
used by `milanapremium.uz`.

The older Flutter experiment remains in [`milana_flutter`](milana_flutter) for
reference. Do not use it for release builds.

## Website

The website, admin panel, API, and SQLite integration are in
[`Claude Code/milana-premium`](Claude%20Code/milana-premium).

Production deployment is intentionally separate from mobile source updates.
