ШРИФТ MONIQA (заголовки, логотип)
=================================
1. Скачайте бесплатный шрифт Moniqa (Latin + Cyrillic, автор Rajesh Rajput):
   https://fontesk.com/moniqa-font/   (кнопка Download, zip)
   либо https://www.behance.net/gallery/114431757/MONIQA-TYPEFACE-Free-Variable-Latin-Cyrillic
2. Из архива возьмите вариативный файл (Variable / VF, стиль Display):
   скопируйте его сюда под именем:  Moniqa.ttf
   курсив (если есть Italic VF):    Moniqa-Italic.ttf
   (есть woff2 — положите также Moniqa.woff2 / Moniqa-Italic.woff2)
3. Обновите сайт с Ctrl+F5.
Пока файлов нет, сайт автоматически использует Cormorant — ничего не ломается.
Лицензия Moniqa: бесплатно для коммерческого использования (см. файл лицензии в архиве).
